RoomVista – Furniture Room Visualisation Tool

# Module
PUSL3122 – HCI, Computer Graphics and Visualisation

# Project Overview
RoomVista is a web-based interactive application designed to support furniture designers during in-store consultations. The system allows designers to create a virtual representation of a customer’s room and visualise furniture layouts using 2D and 3D views.

The application is developed following Human–Computer Interaction (HCI) principles with a focus on usability, accessibility, and effective visualisation.

# Key Features (Planned)
- Secure designer login
- Room creation with size and colour specification
- 2D top-down furniture layout
- 3D room visualisation
- Furniture scaling and colour adjustment
- Save, edit, and delete room designs
- Usability-focused interactions and feedback

# Technologies (Proposed)
- HTML, CSS, JavaScript
- Canvas / Three.js for visualisation
- Firebase (authentication & data storage)
- Figma for UI/UX prototyping

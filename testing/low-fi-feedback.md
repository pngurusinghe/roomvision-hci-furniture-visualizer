# Low-Fidelity Design Feedback – RoomVision

## 1. Purpose
The purpose of this evaluation was to gather early feedback on the low-fidelity UI designs to identify usability issues and improvement opportunities before developing high-fidelity prototypes.

---

## 2. Participants
Two potential users were informally consulted:
- Participant 1: Furniture design student
- Participant 2: Junior interior designer

Participants were selected as they closely represent the target users of the system.

---

## 3. Evaluation Method
An informal walkthrough-based evaluation was conducted. Participants were shown the low-fidelity designs and asked to describe how they would complete key tasks.

The following tasks were discussed:
1. Logging into the system
2. Creating a new room
3. Arranging furniture in 2D
4. Switching to a 3D view
5. Saving a design

---

## 4. Key Feedback Received

### Positive Feedback
- Overall flow of screens was logical and easy to understand
- Clear separation between room setup and design stages
- Drag-and-drop interaction was intuitive

### Identified Issues
- Participants requested clearer visual distinction between 2D and 3D modes
- Furniture scaling controls were not immediately obvious
- Users wanted confirmation feedback when saving designs

---

## 5. Design Improvements Identified
Based on the feedback, the following improvements were planned for the high-fidelity design:
- Add a clear toggle button to switch between 2D and 3D views
- Improve visibility and labelling of scaling controls
- Add visual confirmation messages for save actions

---

## 6. Conclusion
The early feedback highlighted minor usability issues that can be addressed before high-fidelity prototyping. Incorporating this feedback is expected to improve learnability, efficiency, and user confidence in the final system.

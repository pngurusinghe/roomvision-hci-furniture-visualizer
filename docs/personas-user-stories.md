## 2. User Stories

US1. As a designer, I want to log in securely so that my saved designs are protected.

US2. As a designer, I want to enter room dimensions so that the layout matches the customer’s actual room.

US3. As a designer, I want to view the room in a 2D layout so that I can plan furniture placement efficiently.

US4. As a designer, I want to drag and arrange furniture items so that I can quickly explore different layouts.

US5. As a designer, I want to scale furniture items so that they fit accurately within the room dimensions.

US6. As a designer, I want to change furniture and room colours so that I can match the customer’s preferences.

US7. As a designer, I want to switch to a 3D view so that customers can better understand the final design.

US8. As a designer, I want to receive immediate visual feedback for my actions so that I know changes were applied successfully.

US9. As a designer, I want to save and edit designs so that I can reuse them for future consultations.

US10. As a designer, I want undo options so that I can easily recover from mistakes.

# Low-Fidelity UI Design – RoomVision
All Low fiderlity diagrams which are hand driwwen have been included to the report
## 1. Purpose
The purpose of the low-fidelity design phase is to explore layout ideas and interaction flows without focusing on visual aesthetics. This allows early feedback to be gathered and usability issues to be identified before high-fidelity prototyping and implementation.

---

## 2. Key Screens Identified

### Screen 1: Login Screen
- Username/email input
- Password input
- Login button
- Clear error messages for failed login

**Usability Focus**
- Simple layout
- Minimal cognitive load
- Immediate feedback on login status

---

### Screen 2: Room Setup Screen
- Input fields for room width and length
- Colour scheme selector
- Create room button

**Usability Focus**
- Logical input order
- Clear labels and units
- Error prevention for invalid values

---

### Screen 3: 2D Room Layout Editor
- Central canvas displaying room
- Furniture selection panel
- Drag-and-drop interaction
- Scale and rotate controls
- Colour adjustment controls

**Usability Focus**
- Direct manipulation
- Visible affordances
- Immediate visual feedback

---

### Screen 4: 3D Visualisation View
- 3D rendering of the room
- Basic camera controls
- Toggle back to 2D view

**Usability Focus**
- Simple navigation
- Clear distinction between 2D and 3D modes
- Smooth transitions

---

### Screen 5: Save and Manage Designs
- Save design button
- List of saved designs
- Edit and delete options

**Usability Focus**
- Clear system status
- Error prevention and recovery
- Efficient task completion

---

## 3. Storyboard (User Flow)

1. Designer logs into the system.
2. Designer creates a new room by entering dimensions and selecting colours.
3. Designer arranges furniture using the 2D editor.
4. Designer switches to 3D view to present the design.
5. Designer saves the design for future use.

---

## 4. Planned Evaluation
Feedback on these low-fidelity designs will be gathered from potential users to identify layout issues, unclear interactions, and missing functionality before progressing to high-fidelity prototyping.
